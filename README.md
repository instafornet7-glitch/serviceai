# ServiceAI

موقع عربي RTL مبني باستخدام Next.js لمساعدة الباحثين عن عمل. تعمل أدوات الموقع ولوحة المقالات دون اتصال بخدمات قواعد بيانات خارجية؛ تحفظ بيانات المقالات والتصنيفات والإعدادات في `localStorage` داخل المتصفح الحالي.

## التشغيل

1. ثبّت Node.js 20.9 أو أحدث.
2. شغّل `npm install`.
3. شغّل `npm run dev` وافتح `http://localhost:3000`.

لا يحتاج التشغيل المحلي إلى ملف بيئة أو اتصال إنترنت بعد تثبيت الحزم. لا توجد حاجة إلى إعداد قاعدة بيانات.

## لوحة الإدارة المحلية

افتح `/admin/login`. في أول مرة، أدخل البريد الإلكتروني وكلمة مرور محلية لا تقل عن 8 أحرف؛ تُنشأ بيانات المدير على هذا المتصفح. بعد ذلك استخدم البريد وكلمة المرور نفسيهما للدخول.

**تنبيه أمني:** هذا الدخول محلي وتجريبي فقط، وليس حماية حقيقية. بيانات الجلسة وكلمة المرور المجزأة موجودة في مساحة تخزين المتصفح ويمكن تجاوزها أو تعديلها من أدوات المطور. لا تستخدم هذا النمط لمعلومات حساسة أو موقع عام متعدد المستخدمين.

## البيانات والحدود

- المقالات المنشورة والمسودات، التصنيفات، هوية الموقع، التذييل، الإعلانات، وروابط التواصل والسلايدر محفوظة محليًا لكل متصفح.
- تتضمن قاعدة التخزين المحلية مجموعات عامة للخدمات والطلبات والعملاء والطلبات الشرائية، ويمكن استعمال دوال قاعدة البيانات المحلية معها.
- البيانات لا تنتقل بين المتصفحات أو الأجهزة ولا تظهر تلقائيًا عند فتح الموقع من جهاز آخر. مسح بيانات المتصفح يحذفها. خذ نسخة احتياطية قبل تغيير الجهاز أو المتصفح.
- مساحة `localStorage` محدودة بحسب المتصفح؛ تُقيّد صور المقال والسلايدر إلى 1 ميغابايت للصورة وتظهر رسالة عند امتلاء المساحة.
- محتوى `localStorage` خاص بالمتصفح الحالي، لذلك لا يستطيع محرك البحث قراءة المقالات المحلية أو إنشاء بيانات SEO ديناميكية لها. تبقى الصفحات العامة الأساسية قابلة للفهرسة.
- لا تتصل أدوات السيرة الذاتية والتحليل وخطاب التقديم والمقابلات بخدمات ذكاء اصطناعي خارجية.
- إعلانات Google AdSense وخدمات الأطراف الخارجية لا تعمل دون اتصال بالإنترنت.

## الصفحات

- عامة: `/`, `/blog`, `/blog/[slug]`, `/tools`, أدوات السيرة الذاتية والتحليل وATS ورسائل التقديم والمقابلات، `/about`, `/contact`, `/privacy`, `/terms`
- الإدارة المحلية: `/admin/login`, `/admin`, إدارة المقالات والتصنيفات والإعدادات والمظهر والسلايدر والتواصل
- SEO: `/robots.txt`, `/sitemap.xml`
